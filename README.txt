# Proyecto de Terror Multiplayer

Juego de tensiñon psicológica desarrollado en Unity utilizando Photon Fusion para el sistema multiplayer.

## Características

- Multiplayer online
- Sistema de interacción
- Recolección de llaves
- Sistema de stamina
- Menú interactivo 3D
- Créditos interactivos
- Ambientación de terror

---

# Requisitos

- Unity 6
- Photon Fusion

---

# Instrucciones de ejecución

## 1. Clonar el repositorio
## 2. Abrir el proyecto en Unity
## 3. Abrir la escena "main menu"
## 4. Ejecutar el juego
